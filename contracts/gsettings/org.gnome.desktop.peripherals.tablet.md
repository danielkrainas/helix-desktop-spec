# `org.gnome.desktop.peripherals.tablet`

Key surface of the relocatable `org.gnome.desktop.peripherals.tablet` GSettings schema in
gsettings-desktop-schemas 51.0, described through GSettings introspection of
the compiled schema. One copy per device; where Helix keeps them and what it
does with them: `input-settings.md`, "Touchscreens and tablets".

| Key | Type | Default | Allowed values |
|-----|------|---------|----------------|
| `area` | `ad` | `[0.0, 0.0, 0.0, 0.0]` |  |
| `keep-aspect` | `b` | `false` |  |
| `left-handed` | `b` | `false` |  |
| `mapping` | `s` | `'absolute'` | `absolute`, `relative` |
| `output` | `as` | `['', '', '']` |  |
